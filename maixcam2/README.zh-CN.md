# MaixCam2 AI 视觉模块

机器人的"眼睛"。用 YOLOv5 实时检测作物病虫害，同时通过 HSV 颜色分割引导机器人靠近目标作物。装在摄像头云台上，通过 UART 和 STM32 通讯。

## 硬件

- **模块**: Sipeed MaixCam2（AX630C NPU）
- **分辨率**: 摄像头输入 640×480，模型输入 320×224
- **通信**: UART4 (GPIO A21/A22) 接 STM32，WiFi 接基站上传图片

## 模型

用 MaixHub 训练的 YOLOv5 检测模型，导出为三个文件：

| 文件 | 大小 | 说明 |
|------|------|------|
| `model_292463.mud` | <1 KB | 模型元数据 / 类别标签定义 |
| `model_292463_npu.axmodel` | 6.9 MB | NPU 加速推理模型 |
| `model_292463_vnpu.axmodel` | 7.3 MB | VNPU 备选推理模型 |

| Class ID | 标签 | 中文名 | 类型 |

| 1 | baifen | 白粉病 | 病害 |

模型同时也支持猕猴桃和橘子的果实识别，用于地块作物类型匹配，辅助 NFC 校验。

## 视觉引导流程

摄像头对每棵树执行多阶段引导，整个过程由状态机驱动：

1. **ALIGN**（对准）— 检测画面中的绿色植物区域，计算水平偏移量，通过 UART 发 X 轴修正指令给 STM32
2. **MOVE_MONITOR**（前进监控）— 前进时持续跟踪绿色面积占比，做横向微调让机器人始终正对作物中心
3. **DETECT**（检测）— 绿色面积超过 32% 阈值时停车，连续跑 YOLO 推理，记录每种病虫害的最佳帧
4. **UPLOAD**（上传）— 把最好的检测帧通过 WiFi 上传到基站服务器
5. **EXIT**（退出）— 发信号让 STM32 回撤机械臂，前往下一棵树

### 颜色定位原理

YOLO 跑之前先用 HSV 色彩空间做粗定位，比直接用深度学习更快更稳：

- 提取绿色通道，用亮度阈值和 delta 差值过滤背景
- 水平分层分解画面，区分多株相邻植物
- 对每块绿色区域打分（中心距离、面积大小、跟踪连续性扣分）
- 用移动中值滤波消除帧间抖动，输出稳定的定位坐标

所有算法参数都写在 `main.py` 文件顶部，方便现场调试。

## 与 STM32 的 UART 协议

```
AA AA x方向 y方向 x距离高 x距离低 y距离高 y距离低 标志位 FF FF

标志位含义：
  0 = 运动指令，按坐标移动
  1 = 停车 / 目标已锁定 / 开始检测
  2 = 目标丢失，紧急停车
  3 = 距离太近，后退 / 安全停车
  4 = 当前树完成，回撤机械臂
```

## 图片上传协议

上传到 `http://<基站IP>:8000/api/device/images`，multipart/form-data 格式：

```
POST /api/device/images
Content-Type: multipart/form-data

字段说明：
  event_id: 设备事件 ID（需要和已有事件匹配）
  pest_type: 检测到的病虫害标签名
  file: JPEG 图片文件
```

## 部署步骤

1. 用 MaixHub 或 `maixcam2_7_26` 包烧录 MaixPy 固件
2. 修改 `main.py` 里的 `BASE_URL`，指向你的基站地址
3. 把所有文件上传到 MaixCam2
4. 重启 — 摄像头会等待 STM32 发来 READY 信号后才启动检测流程

## 可调参数说明

`main.py` 顶部集中了所有行为参数，改一处就行：

- `DETECT_CONF_TH` (0.60) — YOLO 检测的置信度阈值，越高误检越少但漏检越多
- `STOP_AREA` (0.32) — 绿色面积占比触发停车的阈值
- `DETECT_EXIT_NO_GREEN_MS` (1200) — 连续多少毫秒检测不到绿色判定为树已完成
- `FORWARD_TRAVEL_DIST` (18) — 每棵树最多前进的距离
- `UPLOAD_COOL` (5000) — 两张图片上传之间至少间隔的毫秒数，避免堵网络
